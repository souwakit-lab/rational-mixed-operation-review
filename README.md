# 有理數混合運算複習

四個 Level 的有理數複習活動：

1. 加、減、乘、除單步整數運算，兩個運算數不會同時為正，1,500 XP
2. 其中一個運算數為假分數或帶分數的單步運算，500 XP
3. 無括號的三至四項混合運算，500 XP
4. 括號、分數線、分數與帶分數綜合運算，500 XP

答對獲得 15 XP，答錯扣除 10 XP。答錯後停留在原題，放大顯示正確答案和逐步解答，按「下一題」才繼續。

學生頁面的登出和重置進度均受密碼保護。每班的混沌有理數巨龍擁有 300,000 HP；老師可在大屏查看即時分 Level 統計，並下載學生總體數據與報表。

## 本機預覽

```sh
python3 -m http.server 8080
```

學生頁：`http://localhost:8080/`

老師大屏：`http://localhost:8080/dashboard.html`
